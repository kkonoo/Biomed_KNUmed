# 의과학과 교수진 이름 북

대학원 체험 박람회에서 학부생에게 보여 줄 교수진 소개 책자예요. A4 한 장에 6명씩, 사진 · 이름 · 교실 · 한 줄 소개 · 키워드 · 링크를 넣었어요. PDF에서도 링크를 누르면 열려요.

- `namebook.pdf` — 인쇄용 (표지 1쪽 + 기초의학 7쪽 + 임상의학 5쪽)
- `namebook.html` — 같은 내용을 브라우저로 보기 (휴대폰에서는 카드가 한 줄씩 나와요). 맨 앞에 관심 분야 테스트가 있어요(인쇄에는 안 나와요). 저장소 대문 `index.html`이 이 파일로 연결돼요
- `data/profs.json` — 교수님별 내용. 고칠 때는 이 파일만 고쳐요
- `data/quiz.json` — 테스트 질문 · 결과 유형 · 관심 주제
- `photos/` — 사진 (3:4, 파일 이름은 이메일 아이디)
- `build.py`, `style.css`, `quiz.js` — 만드는 코드, 디자인, 테스트 동작 (색·글꼴은 HaLab 슬라이드 갤러리 blue와 맞춤)
- `fonts/` — Pretendard (SIL OFL, `fonts/LICENSE.txt`)

## 고치고 다시 만들기

```bash
pip install segno
```

```bash
python3 build.py
```

`data/profs.json`의 항목:

| 키 | 내용 |
|---|---|
| `name`, `rank`, `dept`, `kind` | 이름, 직위, 교실, 기초/임상 (기초·임상 순 → 교실 → 이름 순으로 정렬돼요) |
| `line`, `keywords` | 소개말, 키워드 3개 |
| `links` | 카드 아래 링크 `[주소, 글자]` 목록 (여러 개 가능) |
| `contact` | 담당자 `[이름, 연락처]` (연락처가 없으면 `""`, 담당자가 없으면 `null`). 공개 저장소라 웹에도 그대로 보여요 |
| `style`, `topics` | 테스트 추천용. 연구 스타일 3글자(`W`실험/`D`데이터 · `Q`원리/`S`해결 · `C`세포·분자/`P`사람·환자)와 관심 주제 키(`data/quiz.json`의 `topics`) |
| `photo` | 사진 경로 |
| `email`, `source` | 명단 확인용 이메일, 소개말의 근거 (책자에는 안 나와요) |

`source` 값: `flyer` 교수님이 주신 소개말(의과학과 교수 연구팀 소개 전단지) · `bk` BK21 실적 조사 자료 · `dir` 의대 홈페이지 교수 소개 · `pure` 경북대 연구자 포털 · `pubmed` PubMed 논문 · `(확인 필요)` 본인 확인이 필요한 내용

링크는 연구실 홈페이지 → Google Scholar·연구자 프로필 → 의대 홈페이지 교수 소개 페이지 순으로 있는 것을 연결했어요.

## 관심 분야 테스트

9문항(둘 중 하나)으로 연구 스타일 8가지 중 하나가 나오고, 관심 주제를 두 개까지 고르면 잘 맞는 교수님 5분을 추천해요. 주제가 겹치면 3점, 스타일 글자가 같으면 1점씩 더해 점수가 높은 순으로 보여 줘요. 교수님별 `style`·`topics`는 소개말과 실적을 보고 붙인 초안이라 고쳐도 돼요.
