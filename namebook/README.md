# 의과학과 교수진 이름 북

대학원 체험 박람회에서 학부생에게 보여 줄 교수진 소개 책자예요. A4 한 장에 6명씩, 사진 · 이름 · 교실 · 이메일 · 한 줄 소개 · 키워드 · 링크를 넣었어요. PDF에서도 링크를 누르면 열려요.

- `namebook.pdf` — 인쇄용 (표지 1쪽 + 기초의학 7쪽 + 임상의학 5쪽)
- `namebook.html` — 화면용 페이지. [의과대학 연구실 찾기](https://lab-finder-med.knu.ac.kr/)와 같은 틀이에요: 관심 분야 테스트, 이름·교실·키워드 찾기, 구분·교실·주제 칩, 한 쪽에 12분씩 카드(넓은 화면 4·3·2줄, 휴대폰 1줄). 테스트 추천에서 교수님을 누르면 그분 카드가 있는 쪽이 열려요. 저장소 대문 `index.html`이 이 파일로 연결돼요
- `print.html` — PDF를 만드는 A4 책자 (`build.py`가 이 파일을 Chrome으로 인쇄해요)
- `data/profs.json` — 교수님별 내용. 고칠 때는 이 파일만 고쳐요
- `data/quiz.json` — 테스트 질문 · 결과 유형 · 관심 주제
- `photos/` — 사진 (3:4, 파일 이름은 이메일 아이디)
- `build.py` — 위 HTML·PDF를 만드는 코드
- `web.css`, `book.js`, `quiz.js` — 화면 디자인, 교수진 둘러보기(찾기·칩·쪽), 테스트 동작 · `style.css` — 인쇄 책자 디자인 (색·글꼴은 HaLab 슬라이드 갤러리 blue와 맞춤)
- `img/symbol.png` — 머리 줄의 경북대학교 심볼
- `fonts/` — Pretendard (SIL OFL, `fonts/LICENSE.txt`)

## 고치고 다시 만들기

```bash
pip install segno
```

```bash
python3 build.py
```

`data/profs.json`의 항목:

| 키 | 내용 |
|---|---|
| `name`, `rank`, `dept`, `kind` | 이름, 직위, 교실, 기초/임상 (기초·임상 순 → 교실 → 이름 순으로 정렬돼요) |
| `line`, `keywords` | 소개말, 키워드 3개 |
| `links` | 카드 아래 링크 `[주소, 글자]` 목록 (여러 개 가능) |
| `contact` | 담당자 `[이름, 연락처]` (연락처가 없으면 `""`, 담당자가 없으면 `null`). 공개 저장소라 웹에도 그대로 보여요 |
| `style`, `topics` | 테스트 추천용. 연구 스타일 3글자(`W`실험/`D`데이터 · `Q`원리/`S`해결 · `C`세포·분자/`P`사람·환자)(여러 유형이면 `["DQC", "DQP"]`처럼 목록)와 관심 주제 키(`data/quiz.json`의 `topics`) |
| `photo` | 사진 경로 |
| `email` | 카드에 보이는 이메일 (담당자가 교수님 본인이고 연락처가 이 이메일과 같으면 담당자 줄은 빠져요) |
| `source` | 소개말의 근거 (책자에는 안 나와요) |

`source` 값: `flyer` 교수님이 주신 소개말(의과학과 교수 연구팀 소개 전단지) · `bk` BK21 실적 조사 자료 · `dir` 의대 홈페이지 교수 소개 · `pure` 경북대 연구자 포털 · `pubmed` PubMed 논문 · `(확인 필요)` 본인 확인이 필요한 내용

링크는 연구실 홈페이지 → Google Scholar·연구자 프로필 → 의대 홈페이지 교수 소개 페이지 순으로 있는 것을 연결했어요.

## 관심 분야 테스트

9문항(둘 중 하나)으로 연구 스타일 8가지 중 하나가 나오고, 관심 주제를 두 개까지 고르면 잘 맞는 교수님을 5분씩 넘겨 보게 보여 줘요. 같은 유형 교수님 전부와, 주제가 겹치고 스타일이 두 글자 이상 같은 교수님이 나와요(5분이 안 되면 가까운 분으로 채워요). 순서는 주제가 겹치면 3점, 스타일 글자가 같으면 1점씩 더한 점수 순이에요. 교수님별 `style`·`topics`는 소개말과 실적을 보고 붙인 초안이라 고쳐도 돼요.
